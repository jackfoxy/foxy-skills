# `Test.QuickCheck`: the main module

Every symbol exported by `Test.QuickCheck` in QuickCheck 2.19.0.0, in the order and sections of the module's export list (the order Haddock shows). Signatures are from GHCi `:browse` on GHC 9.10.3, with package and module qualifiers removed. `[src]` links point at the definition at the pinned commit. Each row names the skill that explains the symbol in depth.

Stability: everything here is the supported public API. Deprecated (GHC `DEPRECATED` pragmas at 2.19): `withMaxSuccess` (2.18, use `withNumTests`), `printTestCase` (use `counterexample`), `(><)` (use function composition); `morallyDubiousIOProperty` (use `ioProperty`) is only in `Test.QuickCheck.Property`. Re-exported record fields and constructors are listed with their type.
