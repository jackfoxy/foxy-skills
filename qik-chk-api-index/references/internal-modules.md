# Internal modules

These modules are exposed by the package but marked `{-# OPTIONS_HADDOCK hide #-}` and (except `Test.QuickCheck.Text`) have no export list, so every top-level definition is visible. They are implementation details: names and behaviour can change in any release, and nothing here is part of the documented API. `Test.QuickCheck` re-exports selected names from them (for example `Property`, `Testable`, `Args`, `Result`, `Confidence`, `TestProgress`), which are covered in [the main module index](test-quickcheck.md). See [qik-chk-internals](../../qik-chk-internals/SKILL.md) for how the pieces fit together.
